# TCS-ION-Document-Processing-Using-OCR-and-Computer-vVsion
AI-powered document processing system using OCR, NLP, and Machine Learning to extract, classify, and structure data from scanned corporate documents.
📌 AI-Powered Document Processing System

This project presents an end-to-end intelligent document processing pipeline that automates the extraction, classification, and structuring of data from scanned documents using OCR, NLP, and Machine Learning.

Developed as part of the TCS iON AIP curriculum, the system processes multiple document types such as invoices, contracts, emails, memos, reports, receipts, and purchase orders.

🚀 Features
📄 OCR Extraction using Tesseract with optimized PSM selection
🧠 NLP Field Extraction using Regex + NLTK
📊 Document Classification using TF-IDF + Random Forest
🔁 A/B Testing for OCR modes and ML models
🌐 REST API using Flask
💻 Interactive UI with Streamlit
📈 Performance evaluation using Accuracy, Precision, Recall, F1-score

📊 Results
✅ Accuracy: 75%
✅ F1 Score: 0.74
✅ Perfect performance on synthetic data
